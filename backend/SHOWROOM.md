# Showroom Display 2.0

After both GitHub web workflows pass, open `https://display.autosaleumar.com` (or `/display/` on the main domain). Click TV · PAIR. In the authenticated web admin, open Showroom Remote (`/admin/display/`) or iOS Control System → More → Showroom Remote. Enter the 12-character TV code. Commands are written only by authenticated staff; the display polls every 2.5 seconds and reports its current scene about every 12 seconds. A second phone can control the same screen; the latest command wins. A refresh recovers the most recent persistent command, but a pause-only command after a reload cannot recover the exact old frame. The code is per-browser local storage; clearing it produces a new code. Keep the code private. This is not AirPlay or full screen mirroring. No external URL presenter is implemented.

Catalog mode automatically alternates light/dark cycles by default, shows reserved cars with Sale Pending, available new arrivals with Has Arrived, and then the first interior photo when present. New arrival follows the existing 30-day creation-date flag, limited to in-stock/showroom cars. Use the normal catalog gallery to upload PNG cut-outs and additional exterior/interior/detail photos; PNG transparency is preserved in the web and native uploader. In Showroom Remote, select a published vehicle and upload a second PNG/JPEG/WebP showing it under fabric. Use exactly the same scale, pose and canvas as the main photo. The display uses a mask/fade reveal (not physically simulated fabric). Use the remote to pause, resume, select a car, choose a variant/photo, swipe photos, or manually trigger the arrival/reserved presentation. Sold or hidden cars are not shown. The remote uses the first 100 catalog vehicles.

The Radio module accepts licensed MP3, M4A and OGG files up to 20 MiB in the web remote. Select a starting track, play/pause or set volume on either controller. Playback is on the TV. TV browser autoplay can require a local click on «Включить звук». A personal Apple Music subscription is not integrated for commercial playback. No music files are bundled.

Migration 0010 adds three tables only, retaining all data, accounts and existing media. No workflow/secrets/DNS changes required. API access follows the existing session authentication; public screen status is accessible by code, no public commands accepted. Screen heartbeat cannot create records. R2 audio requires a paired screen code. All server assets live in the existing Worker/D1/R2. Browser wake lock remains best effort; Samsung system-level screensaver cannot be guaranteed disabled from a web page.

Checks: strict TypeScript backend typecheck, SQLite migration and simulated API integration with real session auth, Swift parser, frontend TSX syntax. Actual Next.js dependency installation and Xcode SDK are unavailable in the local environment; GitHub build and on-TV testing remain required.
